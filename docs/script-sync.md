# 개인 스크립트 자동 동기화

## 처음 연결

1. 이 기능이 들어간 확장으로 한 번 업데이트한다. 기존 기록은 프롬프트 복사 또는 JSON 저장으로 보관한 뒤 확장을 새로고침한다.
2. 도구모음 팝업의 **스크립트 연결·관리** 또는 작업실의 **스크립트 연결**을 열고 **스크립트 폴더 연결**을 누른다.
3. 저장소 폴더 또는 `local/scripts`를 선택한다. 확장은 해당 스크립트 폴더의 읽기 권한만 사용하며 파일을 쓰거나 삭제하지 않는다.
4. 실행 허용 안내가 나타나면 **Chrome 실행 허용 설정 열기**에서 **사용자 스크립트 허용**을 켜고, 돌아와 **허용 설정 반영하고 계속**을 누른다. Chrome 135–137은 개발자 모드로 허용한다. 이미 켰다면 이 안내는 나타나지 않는다.
5. 새 사이트가 있으면 사용할 주소만 선택해 허용한다. 이미 허용한 사이트에는 다시 요청하지 않는다.

이후 `local/scripts/<id>/script.json`과 실행 파일을 저장하면 작업 목록과 열린 사이트의 버튼에 반영된다. 공통 확장 코드나 manifest를 바꾸면 빌드와 확장 새로고침이 필요하며, 기존에 열려 있던 작업 페이지도 한 번 새로고침한다. UNIST 예제 소스는 자동 등록하지 않는다. 이를 참고해 만든 개인 스크립트도 같은 폴더 연결 방식으로 사용한다.

공통 기능의 빌드를 적용할 때는 연결 화면 아래의 **확장 기능 업데이트 적용**을 사용할 수 있다. 현재 기록이 남아 있거나 스크립트 실행 중이면 업데이트를 막고 저장 안내를 표시한다. 업데이트 후 연결 화면을 다시 열며, 연결한 폴더와 마지막 정상 코드는 유지한다. Chrome이 폴더 읽기 권한을 다시 요청하면 **폴더 읽기 다시 허용**을 누른다.

## 확인 주기와 유지되는 것

- 작업실이나 동기화 화면이 보이면 약 2초 간격으로 확인한다.
- 화면이 닫혀 있어도 Chrome 알람으로 약 30초 간격으로 확인한다. 절전·Chrome 종료 동안에는 확인이 늦어진다.
- 등록한 스크립트와 폴더 핸들은 확장의 IndexedDB에 보관한다. 서비스 워커 재시작과 확장 업데이트 뒤에도 마지막 정상 코드를 다시 등록한다.
- Chrome이 폴더 권한을 다시 요구하면 **폴더 읽기 다시 허용**을 누른다. 폴더 접근을 잃어도 이미 가져온 스크립트는 유지한다.
- **동기화 중지**는 폴더 감지만 중지한다. 마지막으로 가져온 스크립트는 유지하며 보관·삭제는 스크립트 보관함에서 한다.
- 연결한 폴더에서 스크립트 디렉터리를 제거하거나 `enabled: false`로 바꾸면 가져온 실행 목록에서 제외한다. 단순히 파일 저장이 잠깐 불완전해진 경우에는 마지막 정상 버전을 유지한다.
- 보관·삭제 상태는 id로 유지한다. 저장하거나 폴더를 다시 연결해도 삭제한 id를 되살리지 않는다.

파일 변경은 코드와 목록만 갱신한다. 사이트의 업무 작업은 파란 버튼에서 직접 실행한다. 실행 중인 작업에는 새 코드를 덮어쓰지 않으며 완료 후 다음 동기화 때 적용한다.

## 스크립트 작성

기존 `script.json` 형식을 사용한다. `files`에 명시된 폴더 내부 `.js`만 읽는다. 모듈 import 대신 순서대로 로드할 파일을 나열하고, UI 등록은 동기적으로 수행한다. 실제 작업은 `run`에서만 시작한다.

`world: "ISOLATED"`는 개인 코드를 Chrome의 `USER_SCRIPT` world에서 실행한다. 페이지와 확장 content script의 JavaScript 전역에서 분리된다. SAP 기본 API나 기존 MAIN 사이트 기능을 사용하면 `world: "MAIN"`을 지정한다. 각 world의 코드가 수집한 UI 정의는 공통 실행기에 표시하며 입력값·진행 상황·완료 결과를 연결한다. 확장 권한은 사용자 코드에 노출하지 않는다.

잘못된 JSON·JavaScript, 누락된 파일, 등록 실패는 동기화 화면에 표시한다. 마지막 정상 버전이 있으면 유지한다. 실제 페이지에서 초기화가 실패한 스크립트는 오류를 표시하고 다른 스크립트를 계속 사용할 수 있다. 선택자와 사이트 동작은 [제작 안내](create-script.md)에 따라 검증한다.

공식 API: [Chrome userScripts](https://developer.chrome.com/docs/extensions/reference/api/userScripts), [파일·폴더 접근](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access), [Chrome 알람](https://developer.chrome.com/docs/extensions/reference/api/alarms).
