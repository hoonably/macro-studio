# 설치와 사용

## 처음 설치

1. Node.js 22 이상과 Chrome 116 이상을 준비한다.
2. 저장소에서 `npm ci`, `npm run build`를 실행한다.
3. `chrome://extensions`에서 개발자 모드를 켠다.
4. ‘압축해제된 확장 프로그램을 로드’로 저장소의 `dist`를 선택한다.
5. Macro Studio를 도구모음에 고정하고 아이콘을 누른다.
6. 사이드패널의 ‘예제로 사용해 보기’를 열고, 페이지 오른쪽 아래 아이콘 → 폼 입력 예제 → 날짜 → 예제 채우기를 실행한다.

Chrome은 등록한 폴더를 계속 읽으므로 `dist`를 Downloads 같은 임시 위치로 옮기거나 지우지 않는다. 폴더를 옮겼다면 새 위치를 다시 등록한다.

## 이미 만든 매크로 실행

해당 사이트에 로그인하고 작은 파란 아이콘을 누른다. 목록에서 작업을 고른 뒤 날짜 등의 값을 선택해 실행한다. 아이콘은 드래그할 수 있고 사이트별로 위치를 기억한다. 진행 중 메뉴를 닫아도 작업은 계속된다. 오류가 나면 다음 작업을 누르지 말고 메시지와 실제 페이지를 확인한다.

## 새로운 작업 기록

1. 대상 사이트를 연 뒤 도구모음의 Macro Studio를 누른다.
2. ‘이 사이트에서 사용하기’로 그 사이트만 허용한다.
3. 다른 도메인의 iframe이 있다면 추가 프레임 사이트 주소도 허용한다. UNIST의 포탈·SAP 도메인은 기본 프로필에 포함된다.
4. 이름을 적고 ‘새 기록 시작’을 누른다. 이전 기록은 새 기록으로 대체되므로 보관할 기록은 JSON으로 먼저 저장한다.
5. 같은 탭에서 평소 작업을 수행한다. 입력·클릭·페이지 진입이 기록되며, 화면 영상은 저장되지 않는다.
6. ‘기록 끝내기’를 누르고 단계를 검토한다. 기록은 최대 600단계다.
7. 변경할 입력은 변수로 바꾸고 이름을 붙인다. 변수로 바꾸면 원래 입력값도 지운다. 수동 단계는 코드에서 실행하지 않는다.
8. 목적과 변수 설명을 적고 프롬프트를 복사한다. 저장소를 연 Codex·Claude Code에 붙여 넣는다.

기록은 자동으로 완성된 매크로가 아니다. 실제 화면에서 선택자와 대기 조건을 확인하고, 에이전트가 실행 코드를 작성한 뒤 등록한다. [제작 안내](create-script.md)

## 업데이트

코드를 바꾼 뒤 `npm run build` → 확장 카드 새로고침 → 작업 웹페이지 새로고침 순서로 적용한다. 버전 번호는 작은 수정마다 변경하지 않아도 된다.

기존 UNIST 도우미와 이 확장을 동시에 켜두지 않는다. 기존 확장을 끈 뒤 새 확장을 테스트한다. 이 저장소는 기존 확장 폴더를 자동 수정하거나 삭제하지 않는다.
