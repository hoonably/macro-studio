# 설치와 사용

## 처음 시작하기

Chrome 138 이상에서 [Chrome 웹 스토어](https://chromewebstore.google.com/detail/oobgpakpaoknojmgkolgmmkjemjmimld)의 **Chrome에 추가**를 선택한다. Git·Node.js·npm 설치는 필요하지 않다. 처음 목록은 비어 있고 모든 사이트는 OFF다.

1. 사용할 웹사이트를 열고 도구모음의 **Macro Studio → 이 사이트에 적용**을 ON으로 켠다.
2. 페이지의 **파란 버튼 → 새 자동화 만들기**를 누른다.
3. **사용 준비**에서 매크로를 저장할 폴더를 선택하고 읽기·쓰기를 허용한 뒤 경로를 확인한다. 안내에 따라 Chrome의 사용자 스크립트 허용과 대상 사이트 접근을 완료한다. 완료한 설정은 접히며 저장 위치가 한 줄로 남는다. [자세한 연결 방법](script-sync.md)
4. 준비를 마치면 기록 화면이 자동으로 열린다. 이름을 적은 뒤 **기록 시작**을 누른다. 같은 탭에서 평소처럼 작업하고 최종 제출 직전 **기록 끝내기**를 누른다.
5. **전달할 내용 보기**에서 내용과 기록한 동작을 확인하고, 전달하지 않을 단계는 삭제한다. 기록 종료 시 목록이 자동으로 펼쳐지지 않는다. 기록은 화면 영상이 아니며 최대 600단계다. 비밀번호·인증번호는 기록하지 않는다.
6. 작업에 대한 설명을 적고 **에이전트용 지시문 복사**를 누른다. 자세한 내용은 **전달할 내용 보기**에서 검토할 수 있다. 복사한 내용을 Codex·Claude Code 채팅에 붙여넣는다. 저장할 실제 폴더 경로와 파일 작성 규칙도 포함된다.
7. 에이전트가 파일을 만들면 **내 매크로**에서 확인한다. 즉시 확인하려면 **파일 반영 확인**을 누른다. 연결한 폴더 아래 `<id>/script.json`과 `script.js`가 있어야 한다. 파일을 읽어 등록하는 것으로 웹사이트 작업을 실행하지는 않는다.
8. 대상 사이트의 파란 버튼에서 새 매크로를 골라 직접 시험한다. 최종 제출은 직접 한다.

기록과 설명은 에이전트가 실행 코드를 만드는 자료다. 사용자가 설명한 바뀌는 값은 실행 입력으로 만들고 나머지 기록값은 기본값으로 사용한다. 자동으로 분류한 버튼 이름만으로 범위를 정하지 않는다. [제작 안내](create-script.md)

권한은 해당 버튼을 직접 눌렀을 때만 요청한다. macOS의 전체 디스크 접근이나 손쉬운 사용 권한은 필요하지 않다. Chrome은 선택한 폴더 이름만 제공하므로 전체 저장 경로는 처음 한 번 사용자가 확인한다. 설정을 바꾸려면 작업실의 **폴더 설정 · 사이트 설정**을 연다.

## 실행하기

사이트에 로그인한 뒤 파란 버튼에서 매크로를 고르고 날짜 등의 값을 입력해 실행한다. 버튼은 드래그할 수 있고 사이트별 위치를 기억한다. 메뉴를 닫아도 실행은 계속된다. 오류가 나면 메시지와 실제 화면을 먼저 확인한다.

도구모음에서 사이트를 OFF로 바꾸면 새 기록·실행과 파란 버튼이 꺼진다. 기록 중이면 내용을 보존하고 끝내며, 이미 실행 중인 매크로는 완료할 때까지 유지한다. ON/OFF 선택은 재시작 뒤에도 유지된다. 파일을 연결해도 사이트가 자동으로 ON이 되지는 않는다.

## 내 매크로 정리하기

**내 매크로** 화면에서 이름·사이트로 검색하고 **사용 중 / 보관 중** 탭으로 목록을 확인한다.

- **보관**: 실행 목록에서 잠시 뺀다. 바로 **되돌리기**를 누르거나 보관 중 탭에서 **복원**한다.
- **삭제**: 보관 중 탭에서 삭제를 누르고 확인한다. 이 확장에서는 복원할 수 없으며, 원본 파일은 유지된다.
- **파일 반영 확인**: 연결된 폴더의 변경을 즉시 읽는다. 폴더·실행 권한이 필요하면 **폴더·권한 설정**으로 이동한다.

페이지 파란 버튼 안의 보관 아이콘은 확인 팝업을 사용한다. 보관·삭제 상태는 id로 기억하므로 파일을 다시 저장하거나 확장을 새로고침해도 유지된다. 다른 열린 탭의 목록도 갱신한다. 이미 실행 중인 작업을 중단하지 않는다.

## 내부 화면과 업데이트

포탈 안에 다른 사이트의 업무 화면이 있으면 필요한 주소만 선택해 **선택한 내부 화면 허용**을 누른다. 감지된 내부 화면은 모두 접근을 허용해야 다음 단계로 넘어갈 수 있다. 이미 허용한 주소는 다시 요청하지 않는다. 탭 이동과 내부 화면 로드 알림으로 새 주소를 확인하며, 필요하면 **사이트 설정 → 내부 화면 다시 확인**을 누른다. 기록 중에는 다른 탭으로 이동해도 기록 탭이 대상이다.

기록 도중 새 내부 사이트가 나타나면 오른쪽 패널에 허용 안내가 뜨고 기록은 잠시 멈춘다. 패널이 닫혀 있으면 페이지 오른쪽의 **오른쪽에서 허용 안내 열기**를 누른다. **허용하고 기록 계속**을 눌러 Chrome에서 승인하면 기록기 연결 후 기존 기록에 이어서 진행한다. 허용 전에 누르거나 입력한 동작은 기록되지 않으므로 승인 후 해당 화면에서 작업을 이어간다.

화면은 몇 초마다 다시 읽거나 그리지 않는다. 설정 화면으로 돌아왔을 때와 저장·권한 변경 알림을 받았을 때 갱신한다. 파일 변경은 약 30초 간격의 백그라운드 확인으로 자동 반영된다. Chrome 절전·종료 중에는 늦어질 수 있다. 즉시 읽으려면 **내 매크로 → 파일 반영 확인**을 누른다.

공통 확장 업데이트는 Chrome이 관리한다. 로컬 개발판은 빌드가 끝나면 감지해 적용하며 기록·실행 중에는 미룬다. 끝낸 기록과 작성 중인 설명은 복원한다. 화면 아래 **버전 · 업데이트**에서 수동 확인과 알림 설정을 바꿀 수 있다. 알림을 꺼도 자동 업데이트는 유지된다. [개발 안내](DEVELOPMENT.md)

지시문 복사가 성공하면 버튼에 체크 아이콘과 **복사됨**이 표시된다. 이름·목적·바뀌는 값 또는 기록을 수정하면 복사 표시가 초기화된다. 복사에 실패하면 미리보기가 열리고 직접 복사할 수 있다.

상단 메뉴는 **만들기 / 내 매크로** 두 개다. 만들기와 내 매크로 진입 시 공통 준비 상태를 확인한다. 빠진 항목이 있으면 사용 준비를 열고, 완료하면 요청했던 화면으로 바로 돌아간다. 완료한 만들기 화면과 내 매크로 상단에는 현재 경로와 연필 아이콘만 표시한다. 연필 아이콘으로 경로를 수정할 수 있다. 별도의 설정 탭은 없다.

목록의 이름 옆 연필 아이콘으로 이름을 수정한다. 체크 아이콘 또는 Enter로 원본 `script.json`에 저장하고, 취소 아이콘 또는 Escape로 되돌린다. 매크로 ID·실행 코드는 유지되며 사이트 실행 목록에도 새 이름이 반영된다.

실행 화면의 각 입력 옆 잠금 아이콘은 현재 값을 고정하고, 눈 아이콘은 값을 유지한 채 입력란을 숨긴다. 숨긴 입력은 **숨긴 항목**에서 다시 표시할 수 있다. 설정과 고정한 값은 확장이 매크로별로 기억하므로 개인 매크로 파일을 수정할 필요가 없다. 빈 필수 항목은 먼저 입력해야 잠그거나 숨길 수 있다. 새 매크로는 조절 가능한 입력을 기본으로 노출하므로 바꿀 값을 미리 나열할 필요가 없다. 추가 조건도 작업 설명에 함께 적는다.

실행 화면에서도 매크로 제목 옆 연필을 눌러 이름을 바꿀 수 있다. 체크 또는 Enter로 원본에 저장하고, 취소 또는 Escape로 되돌린다. 입력 중인 실행 값과 잠금·숨김 설정은 유지한다.
