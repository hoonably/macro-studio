Macro Studio v1.4.0

기록부터 매크로 실행까지의 흐름을 정리하고 입력 설정을 추가했습니다.

- 각 실행 입력을 현재 값으로 잠그거나 숨기고, 필요할 때 다시 표시할 수 있습니다.
- 내 매크로와 실행 화면에서 이름을 수정해 원본 파일에 저장할 수 있습니다.
- 폴더 읽기·쓰기와 실행 권한을 한곳에서 확인하고, 내부 화면도 같은 오른쪽 패널에서 엽니다.
- 달력·선택 목록·커스텀 입력과 내부 사이트의 동작 기록을 보완했습니다.
- 설정 변경 중 실행 창이 닫히던 문제를 수정하고, 생성 화면과 복사 완료 표시를 정리했습니다.

기존 읽기 전용 폴더 연결은 사용 준비에서 읽기·쓰기 권한을 추가 허용해주세요.
업데이트 후 열어둔 작업 페이지를 새로고침하면 새 실행 화면을 사용할 수 있습니다.
