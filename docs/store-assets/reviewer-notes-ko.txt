검토 안내 · Macro Studio 1.4.0

특정 기관 계정이나 비밀번호는 필요하지 않습니다. 일반 웹페이지에서 사이트 적용을 ON으로 켠 뒤 페이지의 파란 버튼 → 새 자동화 만들기로 기록 작업실을 열 수 있습니다.

사용자는 자신의 빈 로컬 폴더를 선택하고 읽기·쓰기 권한과 전체 경로를 확인합니다. Chrome 확장 세부정보의 사용자 스크립트 허용도 켜야 합니다. 새 설치의 매크로 목록과 기본 호스트 권한은 비어 있습니다. 필요한 origin만 사용자 동작에서 요청합니다.

작업 기록 후 지시문을 복사해 사용자가 별도로 사용하는 코딩 에이전트에 전달합니다. 에이전트가 선택한 폴더에 script.json과 JavaScript를 작성하면 확장은 사용자가 직접 연결한 파일만 읽고 Chrome userScripts로 실행합니다. 개발자 서버에서 코드를 내려받거나 확장 컨텍스트에서 eval/Function을 호출하지 않습니다. 실행은 사용자가 직접 선택하며 최종 제출은 직접 합니다.

폴더 쓰기 권한은 사용자가 이름 변경을 저장할 때 해당 매크로의 script.json에서 name을 수정하는 데 사용합니다. ID와 실행 코드는 이 기능으로 수정하지 않습니다. 잠금·숨김 설정과 해당 값은 확장 로컬 저장소에 보관하며 원본 파일을 변경하지 않습니다.

웹페이지 동작 기록과 입력값·선택자·페이지 식별 정보, 명시적으로 잠금·숨김한 값의 로컬 처리를 개인정보처리방침에 설명했습니다. 외부 분석·광고·수집 서버로 자동 전송하지 않습니다.
