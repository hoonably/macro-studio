# 데이터와 권한

## 저장하는 것

| 데이터 | 위치 | 수명 |
|---|---|---|
| 아이콘 위치 | 각 사이트의 localStorage, 자체 키 | 사용자가 사이트 저장소를 지울 때까지 |
| 클릭·입력 기록 | 확장의 `chrome.storage.session` | 현재 브라우저 세션; 새 기록 시작·기록 지우기·확장 새로고침 등으로 제거될 수 있음 |
| 개인 설정·스크립트 | 저장소의 `local/` | 사용자가 관리 |
| 개인용 빌드 | `dist/` | 다음 빌드까지; 개인값 포함 가능 |
| JSON 내보내기 | 사용자가 저장한 파일 | 사용자가 관리 |

기록은 현재 하나만 보관한다. 새 기록을 시작하면 기존 기록을 대체한다. 중요한 기록은 JSON으로 저장한다.

## 제외하는 것

비밀번호·인증번호·카드 입력과 일반적으로 비밀값을 뜻하는 필드, hidden/file 입력을 건너뛴다. URL query와 fragment는 저장하지 않으며 흔한 토큰 패턴도 지운다. 쿠키·로그인 자격 증명·네트워크 응답·키보드 전체 로그·화면 영상은 읽거나 수집하지 않는다.

이 규칙이 모든 사이트의 개인 정보를 알아내는 것은 아니다. 이름·기관·업무 내용 같은 일반 입력과 URL 경로·페이지 제목·라벨에는 개인 정보가 남을 수 있다. 단계 목록과 프롬프트 미리보기를 확인하고, 변수 전환·단계 삭제로 내용을 정리한다.

기록기의 허용 이벤트에 포함되지 않는 사용자 정의 위젯, closed shadow DOM, 허용하지 않은 출처 프레임 등은 기록되지 않거나 불완전할 수 있다. 중요한 작업은 실제 화면과 읽기 전용 진단으로 보완한다.

## 권한

- `activeTab`: 사용자가 확장을 연 탭에 일시적으로 접근
- `scripting`: 허용된 페이지에 기록기와 아이콘 주입
- `storage`: 기록을 확장 전용 세션 저장소에 보관
- `sidePanel`: 브라우저 옆에 작업실 표시
- 기본 사이트 범위: UNIST 포탈·SAP 및 개인 빌드에서 선언한 스크립트 사이트
- 선택 사이트 범위: 사용자가 ‘이 사이트에서 사용하기’로 허용한 개별 http(s) 사이트

기록은 시작한 탭에서만 수집한다. 허용한 다른 출처 iframe을 같은 탭에서 방문하면 그 이벤트도 포함할 수 있다. 다른 탭은 기록하지 않는다.

## 전송과 공유

확장은 원격 코드·추적·외부 AI 요청을 사용하지 않는다. 사용자가 프롬프트를 복사하거나 JSON을 내려받은 뒤 전달할 상대를 선택한다. 매크로 입력에 따른 대상 사이트 자체 통신은 평소 작업처럼 발생한다.

GitHub에 올릴 때는 `local/`, `dist/`, 캡처·HTML·HAR 등을 제외한다. 공유용 확장은 `npm run build:public`로 별도로 만든다. 공개 저장소의 예제는 개인 실제 설정과 분리되어 있다.
