# 배포 안내

Macro Studio는 Chrome 확장 프로그램으로 배포합니다. macOS 앱용 DMG는 만들지 않습니다. 브라우저가 관리하는 업데이트와 로컬 개발 빌드를 구분합니다.

## 배포 파일

| 명령 | 결과 | 용도 |
| --- | --- | --- |
| `npm run build` | `dist/` | 개인 스크립트를 포함할 수 있는 로컬 설치 |
| `npm run build:public` | `dist-public/` | 개인 스크립트 없는 압축 해제 설치 |
| `npm run package:store` | `dist-store/`, `artifacts/macro-studio-<version>-chrome-store.zip` | Chrome 웹 스토어 업로드 |

공유할 때 `dist`를 사용하지 않습니다. `npm run verify`로 검사하고 업로드용 ZIP의 `manifest.json`이 최상위에 있는지 확인합니다. 빌드·ZIP 생성은 스토어 업로드나 배포 완료를 뜻하지 않습니다.

의미 있는 배포 때만 `package.json`, `package-lock.json`, `extension/manifest.base.json`의 버전을 함께 올립니다. 후속 스토어 업로드는 이전보다 높은 버전이어야 합니다. 검토 중인 작업은 버전을 미리 올리거나 커밋·푸시·게시하지 않습니다.

[스토어 등록·심사 안내](chrome-web-store.md)

## 릴리스 설명

앱을 사용하는 사람에게 달라진 점을 한국어로 짧게 설명합니다. 제목은 `Macro Studio v<version>`, 본문은 **한 문장 요약 → 주요 변경 3~5개 → 필요한 업데이트 안내** 순서로 작성합니다. 통상 5~10줄 정도로 읽히게 하고, 작은 수정은 한 항목으로 묶습니다.

사용자가 볼 수 있는 결과를 먼저 쓰고 내부 파일명·커밋 목록·작업 과정을 나열하지 않습니다. 검증하지 않은 동작이나 아직 배포하지 않은 기능을 완료했다고 쓰지 않습니다. 보안·호환성 때문에 꼭 필요한 주의사항은 생략하지 않습니다.

```text
연결 상태와 업데이트 안내를 한곳에서 확인할 수 있습니다.

- 폴더·스크립트 실행·사이트 권한의 준비 상태를 표시합니다.
- 현재 버전 확인과 새 업데이트 알림 설정을 제공합니다.
- 작업실과 보관함의 간격·문구를 정리했습니다.

업데이트: 웹 스토어판은 Chrome이 자동 적용합니다.
로컬 설치는 코드를 받은 뒤 npm run build를 실행하세요.
```

위 문구는 형식 예시입니다. 실제 배포 버전의 변경과 검사 결과를 확인한 뒤 사용합니다.
