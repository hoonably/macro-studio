사용 준비

확인 중

    매크로를 저장할 폴더를 선택하세요

    원하는 위치에 빈 폴더를 만들어 선택하세요.

    경로를 어디서 복사하나요?

    Mac: Finder에서 폴더를 선택하고 ⌥⌘C를 누르세요.
    Windows: 탐색기 주소 표시줄에서 전체 경로를 복사하세요.
    Chrome은 폴더 이름만 제공하므로 처음 한 번 확인합니다.

    저장 위치

    Chrome에서 매크로 실행을 허용하세요

    1. ‘Chrome 설정 열기’를 누릅니다.
    2. Macro Studio의 사용자 스크립트 허용을 켭니다.
    3. 이 화면으로 돌아와 ‘허용 상태 확인’을 누릅니다.
    설정이 보이지 않나요?

    Chrome 135–137에서는 확장 관리 화면의 개발자 모드를 켜세요.
