    전체 경로 복사 방법

    Mac: Finder에서 선택한 폴더를 클릭하고 ⌥⌘C를 눌러 경로를 복사한 뒤 붙여넣으세요.
    Windows: 탐색기에서 폴더를 열고 주소 표시줄을 클릭한 뒤 전체 경로를 복사하세요.
    Chrome은 선택한 폴더 이름만 알려주므로 처음 한 번 경로 확인이 필요합니다. 폴더 이름이 일치하는지 확인하고 이후 지시문에 자동으로 넣습니다.

    폴더 연결 완료 · 실행 허용만 한 번 켜주세요

    ① 아래 버튼으로 Macro Studio 확장 세부정보를 엽니다. ② ‘사용자 스크립트 허용’을 켭니다. ③ 이 화면으로 돌아와 ‘허용 상태 다시 확인’을 누릅니다. Chrome 135–137에서는 개발자 모드를 켜세요.

    연결한 사용 폴더 아래에 <id>/script.json과 script.js를 함께 저장합니다.

    연결한 폴더에서 스크립트를 추가·수정하면 목록에 자동으로 반영됩니다. script.json에 지정한 파일만 읽으며 원본 파일은 수정하지 않습니다.

    이 화면이나 작업실이 열려 있으면 약 2초마다, 닫혀 있어도 약 30초 간격으로 확인합니다. Chrome이 쉬는 동안에는 확인이 늦어질 수 있습니다.
