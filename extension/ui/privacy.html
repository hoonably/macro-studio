Macro Studio · 데이터와 권한

작업 기록은 내 기기에 저장됩니다

Macro Studio는 사용자가 기록을 시작한 탭에서 클릭·입력·화면 이동과 대상 요소의 라벨·선택자, 페이지 제목·주소의 origin과 경로를 기록합니다. 기록 검토와 개인 매크로 제작에 사용합니다. 일반 입력에는 이름이나 업무 내용이 포함될 수 있습니다.

비밀번호·인증번호·카드 입력으로 식별되는 필드와 hidden/file 입력은 건너뛰며, URL의 query와 fragment는 제거합니다. 모든 사이트의 민감한 값을 완벽하게 식별할 수는 없으므로 공유 전에 단계와 프롬프트를 확인하세요. 쿠키·네트워크 응답·화면 영상은 수집하지 않습니다.

보관과 삭제

현재 기록과 작성 중인 설명은 확장의 세션 저장소에 저장됩니다. 새 기록·기록 지우기·브라우저 종료로 기록이 사라질 수 있습니다. 확장 다시 시작 직전에는 복원용 사본을 확장 전용 IndexedDB에 잠시 두며, 복원 후 지웁니다.

사이트 ON/OFF, 스크립트 상태, 선택한 폴더의 읽기 핸들과 가져온 코드는 확장 저장소에 보관합니다. 업데이트 알림 여부와 Chrome이 알린 새 버전 번호도 로컬에 저장하며 초기화할 때 지웁니다. 사이트 버튼 위치는 해당 사이트의 자체 저장 키에 보관합니다. 동기화 중지는 마지막으로 가져온 코드를 삭제하지 않습니다.

처음 상태로 초기화하면 현재 기록·설명·가져온 코드·폴더 연결·사이트 설정과 추가 권한을 지웁니다. 원본 스크립트·직접 내보낸 JSON 파일·웹사이트 로그인·사이트에 저장된 버튼 위치는 지우지 않습니다. 확장을 제거하면 확장 전용 저장 데이터도 삭제됩니다.

전송과 개인 코드

확장은 광고·분석 SDK, 개발자 서버 전송, 외부 AI 자동 요청을 사용하지 않습니다. 사용자가 프롬프트를 복사하거나 JSON을 저장해 전달할 대상을 선택합니다. 개인 스크립트는 사용자가 선택한 로컬 폴더에서 읽고 Chrome userScripts API로 실행합니다. 선택한 스크립트 자체가 하는 작업과 대상 사이트의 통신은 해당 코드와 사이트에 따릅니다. 신뢰하는 코드만 연결하세요.

필요한 권한

activeTab과 scripting은 사용자가 선택·허용한 탭에 기록기와 버튼을 연결합니다. storage는 로컬 기록·설정을, sidePanel은 작업실을, userScripts는 개인 코드 실행을, alarms는 폴더 변경 확인을 제공합니다. 개별 사이트 권한은 사용자가 ON으로 켜거나 스크립트의 대상 사이트를 선택할 때 요청합니다.

내부 화면 자동 감지의 선택 권한 webNavigation은 작업실이 보이는 동안 대상 탭의 프레임 출처를 확인합니다. 방문 기록 전체를 조회하지 않습니다. 새 출처는 사용자가 선택해 허용해야 합니다. 폴더는 읽기만 하며 파일을 쓰거나 삭제하지 않습니다. 사이트 OFF는 새 기록·실행과 버튼을 끄며, 기존 권한 자체는 Chrome 확장 설정에서 회수할 수 있습니다.

사용자 데이터는 자동화 제공에만 사용하며 판매·광고·신용 평가에 사용하지 않습니다. 문의: Macro Studio 지원. 공개 문의에는 개인 기록이나 인증 정보를 첨부하지 마세요.
