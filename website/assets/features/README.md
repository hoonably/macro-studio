# 기능 화면 출처

현재 `dist-store`의 실제 Macro Studio UI를 로컬 미리보기에서 렌더링하고 Chrome으로 캡처했습니다. 실제 확장의 UI 코드와 스타일을 사용하며, Chrome 확장 API는 메모리 안의 fixture로 대체했습니다.

브라우저에서 실제 UI를 4× 픽셀 밀도로 다시 캡처한 뒤, 웹에서 보기 좋은 2560×2000으로 축소해 저장했습니다. 기존 이미지를 확대하지 않았으며 JPEG 품질 96, 색차 서브샘플링 없음(4:4:4)을 사용합니다.

| 파일 | 크기 | 화면 | 예시 상태 |
| --- | --- | --- | --- |
| `recording.jpg` | 2560×2000 | 작업 기록과 단계 확인 | example.com의 가상 방문 신청, 클릭·입력 세 단계 |
| `agent.jpg` | 2560×2000 | 에이전트와 만들기 | 가상 작업 목표·바뀌는 값·전달 프롬프트 |
| `launcher.jpg` | 2560×2000 | 페이지 안의 작은 실행 버튼과 입력 패널 | 가상 방문 신청 매크로의 실행 전 빈 입력란, 실제 요청을 전송하지 않는 실행 함수 |

사용자의 개인 매크로·브라우저 기록·계정·실제 입력값을 사용하지 않았습니다. 폴더 연결과 저장소도 메모리 fixture이며, 실제 사이트에 요청을 보내거나 신청을 제출하지 않았습니다.

재현용 로컬 도구는 통일 작업 폴더의 `work/macro-feature-preview/server.mjs`입니다. 포트 4186의 `01-recording.html`, `02-agent.html`, `03-launcher.html`에서 현재 UI를 확인할 수 있습니다. 캡션에는 실제 확장 UI를 예시 데이터로 렌더링한 화면임을 표시합니다.
